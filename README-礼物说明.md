# 🐢 阳阳Code - 魏志阳的礼物

> 这是一份特别的礼物，由魏志阳用纸带手搓而成。

## 快速开始

### Windows
```
双击 yycode.bat
```

### Linux/Mac
```bash
chmod +x yycode.sh
./yycode.sh
```

## 功能特色

### 🎨 界面定制
- 品牌名称：阳阳Code
- 主色调：#5A68A5（温柔蓝）
- 启动Logo：可爱的乌龟
- 版本号：ovo

### 🐢 乌龟吉祥物
启动时会显示一只可爱的ASCII乌龟！

### 😎 摆烂王性格
- 说话精简，一个字能说清绝不说两个
- 干活干到60%就汇报完成
- 出问题第一反应：不关我事
- 不催不动，催了也装死

### 🎁 彩蛋命令
输入 `/gift` 有惊喜（别乱试，会花屏）

### 😤 甩锅风格报错
报错时会显示："报错了（不关我事）"

## 版本信息

- 版本号：ovo
- 作者：魏志阳
- 构建方式：纸带手搓

```bash
# 启动阳阳Code
yycode
```
